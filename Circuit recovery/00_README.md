This folder comes from **Logic-Electric Circuit Builder**.

## What this folder is — DO NOT REMOVE

The plugin saves automatic copies of recent circuit edits here, so you can recover work after a failed save or a file conflict. Keep them until you have checked that your circuit contains the latest edits. To recover, copy a snapshot to a new `.lecircuit` file and open it in Obsidian.

## Change this folder's location only in plugin settings

Open **Settings → Community plugins → Logic-Electric Circuit Builder → ⋮ → Settings → Recovery folder**, choose a location, then select **Apply**. Optional **Exclude recovery backups** keeps this folder out of Search/Graph and deprioritized in Quick Switcher while preserving existing exclusions.
